# XY3 bucket visual source

- Title: Plastic Bucket
- Author: MaX3Dd
- Source: https://sketchfab.com/3d-models/plastic-bucket-006d0f237b4141ac93960fa51d6f0634
- License: CC BY 4.0

This asset is used only as a render layer. XY3's original bucket body,
collision boxes, mass/inertia, handle joint, reset pose, and task semantics
remain authoritative.

The physical contract is reused from the preceding A01/YCB scene:
`arena_arm_hand_ycb_tasks_rokae_wuji1.xml` includes `bucket.xml`, and XY3
composes that scene unchanged. The YCB fruit bodies remain the original YCB
assets as well.
