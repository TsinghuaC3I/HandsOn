# XY5 selected lunchbox visual

The lower candidate `lunchbox (1).zip` was evaluated for XY5:

- **Title:** Lunchbox
- **Author:** tjgatt
- **Source:** https://sketchfab.com/3d-models/lunchbox-dc89faa39e2f4f1096630597e4ea6ccb
- **License:** CC BY 4.0

The assembled mesh in `downloaded_plastic_box.usd` is retained as a source reference. It is no longer overlaid on XY5: its visible footprint is approximately 202 x 188 mm, but the existing Clear_Box and Box_lid pair is 292 x 429 mm. Replacing only the box visual hid the actual opening and left an unmatched lid. XY5 now keeps the original matching box and lid visuals together with their existing collision geometry.
