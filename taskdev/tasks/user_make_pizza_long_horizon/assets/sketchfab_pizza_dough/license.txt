This directory contains the publicly downloadable model mesh retained for the
task, converted from the viewer's glTF-compatible source to pizza_dough.glb.
The task's runtime USD conversion applies a solid-white material override to
the external mesh; it does not author or replace geometry. Commercial use is
permitted by the license when the attribution above is retained.
